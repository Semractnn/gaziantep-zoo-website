# Gaziantep Zoo Promotional Website

A multi-page informational and promotional website developed for **Gaziantep Zoo** (*Gaziantep Hayvanat Bahçesi*), showcasing animal species, zoo facilities, visitor guidelines, and seasonal events through interactive media and audio guides.

---

## Key Features

- **Comprehensive Sections:** Dedicated pages for the homepage (`index.html`), about section (`hakkimizda.html`), visitor guide (`rehber.html`), events (`etkinlikler/`), animal categories (`hayvanlar/`), and zoo venues (`mekanlar/`).
- **Rich Multimedia Experience:** Visual galleries (`resimler/`) and animal sound recordings (`sesdosyalari/`) integrated directly into the pages.
- **Modular Styling:** Structured CSS architecture (`card.css`, `css1.css`, `css2.css`, `rehber.css`) for layout organization and card-based content presentation.

---

## Project Structure

gaziantep-zoo-website/
├── etkinlikler/        # Zoo events and activity pages
├── hayvanlar/          # Animal species pages and categorized info
├── mekanlar/           # Zoo facilities, safari & venue pages
├── resimler/           # Images and animated GIF assets (tracked via Git LFS)
├── sesdosyalari/       # Animal audio clips (.mp3)
├── index.html          # Main landing page
├── hakkimizda.html     # About Gaziantep Zoo
├── rehber.html         # Visitor guide & rules
├── card.css            # Card component styles
├── css1.css            # Primary layout styles
├── css2.css            # Secondary page styles
├── rehber.css          # Guide page styles
└── .gitattributes      # Git LFS configuration for large media assets
